# AI For Me｜为我而生的 AI 时代

> 把 AI 时代分散、混乱、真假难辨的信息，**提纯**成普通人、大学生和年轻人能看懂、能判断、能点击原始信源、能形成 **7 天行动计划**的财富机会与副业/学习线索地图。

这不是 AI 资讯站，不是割韭菜导航站，不是课程分销站。它有 **信源分级、机会评分、风险提示、7 天验证计划、本地收藏、投稿入口**。

## ✨ 核心特性

- **今日机会任务板**：信息流 + 轻量仪表盘，每天可回来刷新线索
- **财富线索库**：每条线索带付款人、交付物、原始信源、7 天动作、风险与失败方式
- **深访矿脉**：从访谈/复盘中提炼可复制机会、不可复制条件、付款信号、第一行动
- **城市机会地图**：成都 / 杭州 / 深圳 / 上海 / 北京，含线下安全提醒
- **AI 学习路线**：7 天小白入门，每天对应一个可交付成果
- **风险雷达**：避坑榜，客观标注高风险/争议项目
- **信源等级系统**：S / A / B / C / D / Risk / Expired 公开透明
- **本地收藏**：localStorage 存储「想做 / 已读 / 已行动 / 已放弃」，数据仅存本地
- **7 天验证计划**：每条线索一键生成本地行动模板

## 🧱 技术栈

Vite + React + TypeScript + Tailwind CSS + React Router(Hash) + Framer Motion。
纯静态、零后端，数据在 `src/data/*.ts`。适合 GitHub Pages / Vercel / Netlify。

## 🚀 本地运行

```bash
npm install
npm run dev      # 本地开发
npm run build    # 生产构建（含 tsc 类型检查）
npm run preview  # 预览构建产物
```

## 📁 目录结构

```
src/
  components/   UI 组件
  data/         demo 数据（opportunities / interviews / cities / learning / people / changelog）
  lib/          scoring / filters / sourceLevel / storage / sevenDayPlan
  pages/        首页 / 线索库 / 深访 / 城市 / 学习 / 风险雷达 / 提交 / 关于 / 版本日志
  types.ts      全站类型
```

## 🌐 部署

- **GitHub Pages**：`npm run build` 后将 `dist/` 发布；已使用相对 `base` 与 HashRouter，子路径与刷新均不 404。
- **Vercel / Netlify**：构建命令 `npm run build`，产物目录 `dist`。
